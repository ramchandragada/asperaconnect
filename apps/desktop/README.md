# Aspera Connect desktop

Tauri 2 + React UI for Pro mode (adb/scrcpy) and Easy mode companion.

```bash
# system deps (Ubuntu/Mint/Zorin)
sudo apt install adb scrcpy build-essential pkg-config \
  libwebkit2gtk-4.1-dev librsvg2-dev patchelf libssl-dev \
  libgtk-3-dev libayatana-appindicator3-dev libdbus-1-dev

npm install
npm run tauri:dev
```
