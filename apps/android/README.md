# Aspera Connect companion (Android)

Call-only APK: listens for the Linux PC, places Hub / Zoho click-to-call, and syncs contacts.

1. Build/install from Android Studio or Gradle (`app-debug.apk`).
2. Tap **Start for calls**.
3. Allow **Phone** + **Contacts** (+ ignore battery optimizations on OnePlus).
4. Enter the shown IP in desktop **Phone calls** → **Connect for phone calls**.

No Developer Options. No screen mirroring.
