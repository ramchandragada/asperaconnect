# Install

## Ubuntu / Mint / Zorin

```bash
sudo apt update
sudo apt install adb scrcpy
# then install the .deb from GitHub Releases
sudo apt install ./aspera-connect_*.deb
```

## Fedora

```bash
sudo dnf install android-tools scrcpy
# install AppImage or build from source
```

## Arch

```bash
sudo pacman -S android-tools scrcpy
# AUR package welcome — build from source for now
```
