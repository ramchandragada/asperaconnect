# First mirror (Pro mode)

1. Install `adb` and `scrcpy`.
2. On Android: enable **Developer options** → **USB debugging**.
3. Connect USB, unlock phone, tap **Allow**.
4. Open Aspera Connect → **Start mirror**.

## Wireless

1. Enable **Wireless debugging**.
2. In Aspera Connect → **Wireless**: enter pairing IP:port + 6-digit code → **Pair**.
3. Enter connection IP:port → **Connect**.
4. **Start mirror**.
